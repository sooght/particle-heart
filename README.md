# Particle Heart · 动态粒子爱心 ❤

> 万千炫彩粒子从屏幕底部喷涌而上，汇聚成一颗持续"呼吸"搏动的爱心。

纯黑背景 · 加法混合辉光 · 梦幻拖尾 · 粉/浅粉/紫/淡紫渐变 · 60 FPS

## 运行

```bash
pip install -r requirements.txt
python heart_particles.py
```

## 操作

| 按键 | 功能 |
| ---- | ---- |
| `空格` | 重新绽放（重置全部粒子） |
| `ESC` | 退出 |

## 实现原理

1. **爱心参数方程**：`x = 16sin³t`，`y = 13cos t − 5cos 2t − 2cos 3t − cos 4t`；轮廓粒子直接取方程值，内部粒子向中心随机收缩，构成实心爱心。
2. **弹簧汇聚物理**：每个粒子持有 位置/速度/加速度/颜色/大小/透明度 属性，加速度 `a = k·(目标 − 位置)`，配合阻尼与限速，远处冲刺、临近缓降，轨迹自然弯成喷泉状弧线。
3. **呼吸与抖动**：抵达后目标点随 `breath = 1 + 0.075·sin(1.6t)` 整体胀缩，叠加各粒子独立相位的正弦微抖，整颗爱心如心跳般搏动。
4. **发光渲染**：预渲染径向渐变光晕贴图，以 `BLEND_RGB_ADD` 加法混合绘制，重叠处过曝发白；每帧覆盖半透明黑形成拖尾。

## 可调参数（脚本顶部）

| 参数 | 说明 | 默认值 |
| ---- | ---- | ---- |
| `TOTAL_PARTICLES` | 粒子总数 | 3600 |
| `SPAWN_PER_FRAME` | 每帧喷涌粒子数 | 16 |
| `HEART_SCALE` | 爱心大小 | 17.0 |
| `BREATH_SPEED` / `BREATH_DEPTH` | 呼吸速度 / 幅度 | 1.6 / 0.075 |
| `TRAIL_ALPHA` | 拖尾强度 | 42 |
| `JITTER_AMP` | 抵达后抖动幅度 | 1.3 |
